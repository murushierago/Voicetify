# Voicetify

A lightweight Android app that announces the **artist and track title** when a new song starts playing in Spotify. Great for listening to new music without checking your phone.

## Features
- 🔊 Announces the artist and song using Android text-to-speech
- ⏯️ Can pause Spotify while speaking and resume afterward
- 🔘 Turn announcements on or off at any time
- 🔒 Works in the background with notification access enabled
- No Spotify login or API key required

## Download & install
1. Download the latest APK from **[GitHub Releases](https://github.com/murushierago/Voicetify/releases)**.
2. Install it on an Android device (Android 8.0+).
3. Open Voicetify and grant **notification access**.
4. Enable announcements and play music in Spotify.

> **Beta:** Behavior may vary across Android devices and Spotify Connect sessions. If you control playback on another device, turn announcements off to keep your phone quiet.

Voicetify is an independent project and is not affiliated with Spotify.
